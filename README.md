# How AI Coders Discuss, Disagree, and Reach Consensus: Challenges and Design Opportunities for LLM-Based Qualitative Coding

This repository contains discussion data from AI coders, a coding pipeline overview, and detailed prompt designs used in the process.

### FILE 1. `AI_coders_discussions.zip`

This zip file contains discussions between AI agents to resolve conflicts in qualitative coding across four different datasets. Each text file follows a structure below:

- **Data ID**
- **Excerpt of Data for Coding**
- **Coder 1’s Initial Opinion**
  - Assigned Label
  - Reasoning
- **Excerpt (Repeated)**
- **Coder 2’s Initial Opinion**
  - Assigned Label
  - Reasoning
- **Discussion Thread**
  - Back-and-forth dialogue between coders

---

### FILE 2. `Coding Pipeline.pdf`

This document outlines the automated coding pipeline powered by LLM agents. It covers the end-to-end flow of the coding process along with all the functions in the process.

---

### FILE 3. `Prompt Design.pdf`

This file provides a detailed explanation of the prompt design used to guide LLM agents during:

- Initial coding (label assignment with justification)
- Conflict resolution discussions (agent-to-agent negotiation)
